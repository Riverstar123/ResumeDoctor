# SC-01：确定性评分交付

对应 #11，D（mysteriesy）负责；本轮用户指定 A（Riverstar123）评审。公共工程 #38 已合并。只实现给定状态的纯评分，不实现匹配、HTTP、数据库或模型调用。

入口：`from app.scoring import calculate_score, ScoringError`。调用 `calculate_score(assessments, "coverage-v1")` 返回共享 `ScoreResult`，匹配器版本固定为本次唯一支持的 `matcher-v1`。调用方先排除 ignored 要求；评分器拒绝空输入、重复 ID、权重/状态系数不一致和未知版本，不静默修复输入。

数字来源为 [评分规则](../05-scoring.md) 和 [诊断样例](../examples/diagnosis-item.json)：基准 66.7、未知比例 0.1667、技能 60、学历 100；must 权重 2，preferred 权重 1；四种状态系数 1/0.5/0/0。计算使用 Decimal 与 ROUND_HALF_UP，类别无要求时不输出，总分不平均类别分数。返回 DTO 是独立副本，输入不会被修改。

内部 `ScoringError.code` 中 `NO_SCORABLE_REQUIREMENTS` 由 A 映射 HTTP 422；其他非法状态也由 A 处理，M4 不返回 HTTP 响应。

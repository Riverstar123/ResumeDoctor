# 结构化条件与 coverage-v2 验收记录

## 范围与兼容

本次修复覆盖 M1–M5：PDF 阅读顺序、可追溯的事实属性、通用 AND/OR 条件、证书进度、未来到岗安排、确定性匹配，以及报告的事实审核。不是针对某份简历或某个岗位提高分数；不支持的条件保留人工判断。

新诊断使用 `coverage-v2 / matcher-v2`。仅人工评价和规则不支持项从自动评分分母排除；缺证据、冲突及明确不满足仍计入。页面同时显示自动计分范围和未知权重。旧快照保持原样，无数据库迁移；旧档案缺少结构化属性时不猜值。

契约和前端类型同步，用户可查看、编辑新增属性和条件，保存新版本后重新确认。当前提示词为 `profile-v5 / chat-v8 / job-v3 / report-v7`，独立审核为 `report-grounding-v6`；模型目录为 `models-v4`。仅实际型号 `deepseek-flash` 显式禁用 thinking，保留独立报告事实审核、原有任务时限和重试上限。

# 经历与岗位确认简化（Issue #70）

## 用户体验与范围

用户授权优化电脑端确认流程。经历卡片默认显示标签、学历或取值、日期、完成状态、肯定/否定、应用情况和一段原文摘要；点击展开原有编辑字段。全部原文依据集中折叠，仍可查看和编辑。岗位卡片直接显示招聘原文、必须/优先/忽略状态和核对目标；确认操作栏在电脑端保持可见。

新增空条目默认展开；保存校验失败时展开对应字段，错误链接可定位输入框。折叠不改变数据，修改后仍须保存并重新确认。没有增加接口、依赖或改动历史版本。没有单独优化手机布局。

## 岗位要求整理

`job-v3` 明确“一种工具用于一项工作”保留完整引用并提取一个工具应用要求，例如“能用 Python 清洗和分析金融数据”。服务端仅对完整引用相同、均为 skill/has_skill、工具名及动作对象能明确对应的重复项规范化，再使用既有去重和冲突规则。不会仅凭同一句原文合并 Python 与 SQL 等独立技能，不合并学历、月数或独立成果要求。忽略状态冲突仍报错。

这是有限的句式修正，不是通用语义匹配。评分公式、证据不足的处理和报告生成未改变；不会把没有的经历编出来，也不能据此保证所有真实模型输出都不重复。旧岗位需重新提取或编辑形成新版本才使用新内容。

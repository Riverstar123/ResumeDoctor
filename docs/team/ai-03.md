1. 组长从 `backend/.env.example` 复制 `backend/.env`，本地填写 `LLM_MODE=real`、`LLM_PROVIDER=openai_compatible`、`LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`、`LLM_MODEL_A`、`LLM_MODEL_B`（A、B 必须是两个不同的实际模型名）；密钥只在本机，E 不要求公开发送。

3. 在 `frontend/` 执行（告知文案按实际供应商填写）：
   ```sh
   RD_AI03_MODE=real RD_AI03_PG_HOME="$RD_QA03_PG_HOME" \
   RD_AI03_NOTICE="本页面将合成简历/JD 发送至 <供应商实际模型> 用于提取与报告生成；仅本次诊断使用……" \
   npm run test:e2e:ai03
   ```
4. 回填证据：把 `test-results/ai03/evidence/` 的 JSON/PNG 脱敏核对后复制到 `docs/team/evidence/ai-03/` 并提交；回填上表与费用/限额核对（供应商官方信息，不预填）。
5. 验收后组长将 `.env` 改回 `LLM_MODE=fake` 重启，页面恢复演示标记；真实 `.env` 不提交。

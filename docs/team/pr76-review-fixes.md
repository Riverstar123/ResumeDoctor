## 审核拒绝的边界

额外覆盖多个 choices、重复 JSON 对象键（封装及工具参数）、混合文本与工具结果、未完成 JSON。
这些响应可能掩盖否决，不能抽取其中一个看似通过的结果。重复键不能通过后值覆盖前值消除
unsupported；普通日志仍不记录原文或真实键名。离线回放与实际 HTTP 使用相同的唯一键检查。

生成可使用原有一次重试；审核一旦发出不补发。正常两次请求，生成重试时最多三次，仍共享原有
总期限。明确拒绝的可选项只有在完整、合法的单次审核中才可被筛除；其他内容的保留门禁不变。
此调整优先保留审核可信性，审核传输临时失败时也会保留评分而不再自动付费重试。
